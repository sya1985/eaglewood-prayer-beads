# 人工处理痕迹识别

> 材质真假须仪器定性（CMA）。本表列的是看图能识别的处理痕迹——
> 用于排序疑点，不用于下定论。

---

## 判据基础：沉香的三大结构

天然沉香的木质部有三个可辨识结构，微距／显微判据全部围绕这三者的有无与形态展开：

| 结构 | 是什么 | 放大下的样子 |
|---|---|---|
| 韧皮部 | 油脂主要贮存处（含油腺／树脂道） | 成片分布的深色油区 |
| 导管 | 输水管道 | 圆形／椭圆形孔洞 |
| 木射线 | 径向薄壁组织 | 放射状细线 |

- 三者齐全 + 排列自然 ＝ 天然沉香的木质基础
- 判读顺序固定：先看三个结构在不在 → 再看有没有变形、糊化、被油填掉

## 识别表（外观图／普通照片）

| 手法 | 看图能判 | 识别特征 | 必须靠什么定性 |
|---|---|---|---|
| 杂木（非沉香材） | 可靠识别 | 纹路是导管结构——蜂窝孔、点状短划线布满珠面；无油脂腺斑块 | CMA 检测（最硬） |
| 微压（压制） | 可靠识别 | 等距等宽的平行横纹，每颗纹路几乎一样——模具形成，天然料做不到 | 放大镜／微距看纹路是否为模具压印（见下节） |
| 高压（压缩沉） | 仅线索 | 表面非常光亮（密度加大所致；注意与高抛的"硬亮"区分） | 微距看结构（见下节） |
| 高抛 | 可靠识别 | 反光偏硬（玻璃／塑料感）而非温润；木纹被磨浅、油脂透亮感被磨掉；表面烧焦发黑、内部却是白的 | 侧光对比 + 看孔道口／断面；微距看磨痕与油线（见下节） |
| 煮油／抹油／泡油 | 仅线索 | 颜色偏深且过于均匀、油光浮在表面而非从内部透出、每颗色差极小 | 上手摸：发黏＝抹油；微距看结构（见下节） |
| 染色 | 仅线索 | 颜色鲜艳均匀、与木纹走向无关、过渡突兀 | 看断面／沉水掉色 |
| 注油（真空针注／微注油） | 仅线索 | 密度异常偏高（> 1.1） + 油光只在针孔附近。⚠️ 天然沉水上限约 1.2，1.1–1.25 是天然与仿品的重叠带，必须叠加"油光只在针孔附近"才成立 | 孔道口放大；微距看结构（见下节） |
| 注胶 | 看不出 | 纯图片无解；只能靠克重异常偏重间接提示（同珠径密度虚高） | 热针／CT |
| 香精 | 看不出 | 香味不在图里 | 隔袋闻／燃烧看烟 |

## 微距／显微镜判据

> 前提：以下每一条都要求有微距图（显微镜图）——三大结构的表现远比外观可靠。
> 没有微距图就退回上一节的外观判据。

| 手法 | 放大观察下的判据 | 一句话抓法 |
|---|---|---|
| 杂木（非沉香材） | 韧皮部、导管、木射线三大结构全不具备（花奇楠、楠木类、粉压缩类假沉香，及其他含油杂木） | 三样都没有 |
| 微压（压制） | 三结构还在，但发生变形 —— 看导管、射线是否变形；尤其看木质纤维是否还保留、纤维排列是否自然 | 结构对但被压歪、纤维不自然 |
| 煮油／抹油／泡油 | 三大结构都存在，但含糊不清 | 三样都在但糊掉了 |
| 高压（压缩沉） | 一般只剩韧皮部可见，且韧皮部非常密集、甚至扭曲变形；因密度加大，表面非常光亮 | 只剩一片密油、表面发亮 |
| 微注油 | 表面有油的部分，韧皮部内却没油／油不饱和，油反而在周边 | 油在腺外，不在腺内 |
| 高抛 | 木质部颜色深，但韧皮部（油线孔）空洞或颜色发白；高抛痕规则笔直，与天然沉香油线的不规则、大小不一、走向各异形成对比 | 料色深而油线孔发白、磨痕笔直 |

## 四条关键提醒

### 1. 「处理」就是造假，没有"只是工艺"一说

图上看得出的人为干预，都是为了让料显得比实际更好，都属造假 —— 只是手法不同：

- 高抛、煮油／抹油／泡油、染色：料本身可能仍是真沉香，但被做出更好的品相（更深、更亮、
  更"油"）→ 以次充好。高抛＝高速摩擦把表面烧深烧亮，用来制造"色深＝结香久、油足"的观感。
- 注胶、注油、香精：改变材质或直接冒充 → 以假乱真。

### 2. 两个轴别混：性质 vs 证据强度

「是不是造假」是性质，图上即可判断；「能不能下定论」是证据强度，
图片只到"迹象"（见第 4 条）。看不出痕迹 ≠ 没处理（注胶、香精图上无解）。

### 3. 可能叠加

注胶 + 染色 + 高抛可能同时上——发现任一项时不要就此打住，单看这一项都不足以定性。
卡片里要写成"XX 迹象"，不能写"是 XX"。

### 4. 用于排序，不用于定性

正确用语：「⚠️ 杂木迹象（非沉香材）——蜂窝状密集孔洞是阔叶材导管结构」
错误用语：「这串是假货」

## 可靠识别 vs 仅线索：怎么在卡片里体现

- 可靠识别的项（微压／高抛／杂木）→ 写成硬伤，直接进入"建议回避"的依据
- 仅线索的项（高压／煮油／抹油／泡油／染色／注油）→ 同样写"建议回避"，但结论行必须带限定语
  「线索不充足 —— 建议补拍后重判」，并列出要补拍／实测的具体项
- 看不出的项（注胶／香精）→ 不写进卡片，避免误导；只在"待补信息"里提示需要什么方式验
- 有微距图时，"仅线索"可升级为可靠识别：
  - 高压 —— 只剩密集、扭曲的韧皮部，结构证据明确 → 可按可靠识别写
  - 微注油 —— 能直接看到"油在腺外、不在腺内" → 可按可靠识别写
  - 煮油／抹油／泡油 —— 只到"结构被糊化"，仍作疑点

定价去向（见 `pricing-model.md` §5.2）：图上看得出的人为干预，
不论改造料质（注油、压缩沉、注胶、香精）还是只美化品相（高抛、抹油／煮油／泡油、微压），
一律写「建议回避」，都不出估价上限。
