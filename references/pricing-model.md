# 定价模型

> 核心思想：标签会骗人，克重和纹路不会。 用克重反算密度锁定"料有多实"，  
> 用图像观察锁定"料有多好"，两者交叉得到价格区间。

---

## 一、密度反算（第一步，必须先做）

### 公式

```
单颗体积 V = 4/3 × π × r³          （r = 珠径 ÷ 2，单位 cm）
密度 ρ     = 克重 w ÷ (V × 颗数 n)
```

### 沉水等级（民间口径 · 三档）

≥ 1.00 沉水｜0.80 – 0.99 沉水浮｜< 0.80 不沉水。另有九分沉 ≈ 0.90、八分沉 ≈ 0.80、  
半沉 ≈ 0.50 等叫法，无标准依据、各源不统一，不参与判档 —— 一律以实测密度为准；要判某串取哪栏  
基准，用实测密度对 `region-benchmarks.md` §一 1.1 的三档密度栏。

⚠️ 跨档因素两个：
- 含水率：干透与否直接影响沉浮 —— 沉水料失水后变成沉水浮很常见。实测须注明干湿状态，非干透状态下的沉浮结论不成立。
- 高压：高压（压缩沉）能把不沉的压进沉水浮、把沉水浮压进沉水 → 反算密度明显高于外观所支撑的油量时，先复核处理痕迹（见 `treatment-marks.md`）。

密度不是全部：熟结、软油料常不沉水而香韵极好 → 密度档只是定价轴之一，不单独决定等级。

### 缺珠径时反推珠径

用户没给珠径、图上也读不出时，用颗数 + 克重配合假想密度反推：

```
D(mm) = 20 × ( 3w / (4π · n · ρ) )^(1/3)
```

实操：分别代入 ρ = 0.95 / 1.05，得到珠径区间，再与图上珠子比例目测比对收敛。

### ⚠️ 珠径是密度结论的命门

珠径 10mm → 11mm，密度直接掉约 25%（1.17 → 0.88）。  
珠径无吊牌标注时，密度必须按区间给，不能给单值，并在卡片里标注"珠径待确认"。

### ⚠️ 密度等级必须和外观对得上

密度是从克重反算的，而克重是卖家报的。所以密度结论出来后再做一道外观交叉校验：

| 反算密度                   | 理应看到的外观                                | 外观相反则说明                                 |
| ---------------------- | -------------------------------------- | --------------------------------------- |
| ≥ 1.00（沉水）             | 油线饱满、色泽深沉，基本看不到裸露棕眼                    | 克重虚报，或实际珠径更大 → 密度结论失效                   |
| < 0.80（不沉水）            | 导管孔裸露、浅色木纤维为主                          | 与等级自洽，属正常                               |

密度高、珠面却导管孔裸露、油线稀薄 —— 不是"料不好"，而是克重报高了或珠径被低估，两者都直接  
推翻密度等级 → 卡片写「密度与外观不相称」，珠径实测列为第一号待确认项，不要只当"料质一般"处理。

### ⚠️ 天然密度有上限：反算值过高同样是警报

密度过高和过低一样要查（多来源 2026 交叉）。⚠️ 本表判「这个密度真不真」，不是等级命名；  
等级一律以 §沉水等级 表为准（两表边界不同），引用时只写等级表的名。

| 密度 ρ        | 判读                                         |
| ----------- | ------------------------------------------ |
| 0.35 – 0.55 | 白木级，完全漂浮                                   |
| 0.55 – 0.80 | 含油中等，通常仍不沉                                 |
| 0.80 – 1.00 | 接近沉水，未达门槛                                  |
| 1.00 – 1.20 | 天然可沉水（高油）                                  |
| 1.10 – 1.45 | 压缩沉／高压注油仿品区间（与天然上限重叠）                      |
| ≥ 1.50      | 大概率注胶（胶水密度 1.2–1.8）                        |

两条实操提醒：

1. 反算落在 1.15–1.25 时不要直接坐实「沉水」 —— 这是天然上限与仿品区间的重叠带。  
   卡片里写成「密度顶天然上限」并列出复验项，而不是写成"沉水达标、放心"。
2. 星洲系新料含水率会虚高密度：刚开出来的料可能暂时 > 1.0，放一段时间水分散掉后跌到 0.9 以下，  
   从"沉水"变"不沉水"。沉水测试应在恒温恒湿干置 2–4 周后做，新料直接测没有参考价值。

→ 因此在密度处于重叠带的标的上，复验顺序是：  
① 干置后常温冷水沉水实测（不是热水——热水会把珠子内部空气挤出，不沉的也能短暂下沉）  
② 复称克重 + 实测珠径（反算的两个输入都要复核）  
③ 孔道口放大查针孔注油

### ⚠️ 随形件：克重反算不成立

随形件（方糖形／随料形）不是球体，球体积公式不能用。实操规则：

1. 禁止用球公式给随形件算密度 —— 会得到虚高的假密度。同一串 8.3g÷14 颗：  
   误按 10mm 圆珠算得 1.13（"沉水"），按方体粗估只有 0.59（不沉水），差近一倍。
2. 要么实测（常温冷水沉水试验／排水法量体积），要么方体近似并标注假设：  
   体积 ≈ 长 × 宽 × 厚，其中厚度最难从图上判断，是最大误差源。
3. 卡片里写「无法反算」，同时给出反推上限——这个比体积估算直观得多：
   > 若要沉水，单颗体积须 ≤ 单颗克重 ÷ 1.05
   例：8.3g ÷ 14 颗 → 单颗 ≤ 0.565 cm³（约 8.3mm 见方）。拿这个上限跟图上珠型一比，  
   矛盾立刻可见。比给一个来路不明的密度值有用得多。

⚠️ 随形件的「沉水」标签默认按「未核实」处理，除非用户已做沉水实测或排水法。

### ⚠️ 桶珠／鼓珠：不是球体，用圆柱近似

桶珠（鼓珠、桶形珠——圆柱带圆角）体积比同直径圆珠大 1.5–2 倍，  
套球公式会得到虚高的假密度（方向与随形件相反，但同样是错的）：

```
圆柱 V = π × r² × h          （r = 直径 ÷ 2，h = 珠长，单位 cm）
桶珠近似 V ≈ 圆柱 × 0.85      （两端圆角削去的部分）
```

| 假设                        | 8×9mm 桶珠 23 颗 / 6g 的 ρ                  |
| ------------------------- | --------------------------------------- |
| 圆柱（8×9mm）                 | 0.577（不沉水）                              |
| 桶珠（圆柱 ×0.85）              | 0.678（不沉水）                              |
| 误用球公式（当 8mm 圆珠）           | 0.973 ← 虚高 1.7 倍，会被误判成"沉水浮"             |

判定顺序：① 先从图上确认是不是桶珠（明显圆柱状、两端平）→ ② 用圆柱近似，  
卡片必须标注这是形状假设 → ③ 反算只用标注珠径与实物形状，不要拿"体积等效球径"去凑档位。

⚠️ 桶珠在形状系数表里取 ×1.00 —— 它的方向是低于圆珠（费料仅次于圆珠），  
但无量级来源，故保守按 ×1.00 处理并在卡片注明。不要自行外推新系数档（同 §三 3.3 规则）。

### ⚠️ 带佛头（三通塔）的串：克重口径要先减

佛头（三通 + 塔）与珠子不是同一形制，它的重量混在总克重里，  
直接拿总重反算会污染密度。业内口径：有三通佛头的，沉水标准可适当加 0.5–1 克  
（即要按"总重 − 0.5~1g"去比对沉水门槛）。

实操：

1. 优先要素珠部分的克重 —— 唯一能精确反算的口径
2. 素珠克重拿不到、且佛头同料时：按减 0.5 g 与减 1.0 g 各反算一遍，密度写区间；
   两算结果跨档时按低档报，卡片注明「含佛头，克重按 0.5–1g 估计扣除」
3. 佛头异料或材质确认不了（传统常配蜜蜡、绿松石、南红、银做三通／佛头，不能默认同料）
   → 无法反算，密度写待确认，沉水档不得声明
4. 单圈手串基本不做佛塔（费料、无统一形制），遇到时先当留意项：流通真货极少，不少是仿品照普通木串做的"标配"

⚠️ 佛头对密度的影响是"高估"方向 —— 佛头多为实心、无穿心孔，比同径圆珠重，  
不减会让反算密度偏高，把一串不沉水料误读成沉水浮。

⚠️ 反过来，若塔珠是主体形态（整串塔形珠），不属于本节的"配件"情形 —— 先分清佛头是"配件"还是"主体"。

## 二、克单价档位（只回答该查哪条基准）

> ⚠️ 同产区同品质下，克单价仍可跨档，差别在油脂分布是否饱满贯通。
> 所以「档位」不是一串数字，是「材质档 → 一条基准查询」的映射。

| 材质档（由可核实项判） | 该取的原料价栏（`region-benchmarks.md` §一 1.1） |
| ----------- | -------------------------------------- |
| 种植料／浮水／优化料  | 同产区「浮水料」栏                              |
| 中端半沉水       | 同产区「半沉 – 九分沉」栏                         |
| 一线八九分沉      | 同产区「半沉 – 九分沉」栏                         |
| 近沉水（半沉偏沉）   | 同产区「半沉 – 九分沉」栏（偏沉端）                    |
| 真沉水·入门级     | 同产区「沉水料」栏                              |
| 真沉水·天然老料    | 同产区「沉水料」栏（老料／上端）                       |
| 收藏级／奇楠种     | 顶级行原料价（§一 1.2 用法）；无报价就不出上限             |

⚠️ 1.1 表是原料口径。 成品克单价 = 表内原料价 × 3–5（推演桥，
见 `region-benchmarks.md` §二 2.3），过桥后才进 §四 的估价公式。

⚠️ 可用基准的唯一出处是 §一 1.1 表。 本文件不复制第二套数字 ——
两处各存一套，是同一个 skill 里最容易分叉的病根。
表内该产区无报价（「-」）时不出上限，只给量级描述并注明「基准未核实」（见 §四）。

### 倒挂信号（两个方向都是警报）

- 中端产区报高价（东马／富国岛／斯里兰卡报出接近一线门槛的价）→ 料不对或被做价
- 一线产区报低价（文莱／达拉干／马尼捞报出中端档以内的价）→ 标签存疑，几乎必然非该产区真品

## 三、四个价格系数（在同一克单价档位内做上下浮动）

### 3.1 油脂分布系数（主导系数，幅度最大）

| 观察                               | 判据（必须落到图上看）                        | 系数         |
| -------------------------------- | ---------------------------------- | ---------- |
| 全串油润且分布均匀，每颗含油接近                 | 逐颗都有油相，找不出成片干白木                    | × 1.25     |
| 油润为主，部分珠／局部偏干                    | 偏干只在个别珠或小片；底色仍见油光                  | × 1.00     |
| 多颗珠面成片干白木、导管孔裸露                  | 干白木成片、肉眼即见，油相零星                    | × 0.8      |

判定要点：油线是否贯通连续、每颗含油量是否接近、有无局部干白芯。  
同为"润"，全串均匀油润属稀缺（上浮）；多颗珠成片干白木则低一档。

⚠️ 花纹料（虎斑／虎皮／条纹料）没有正好对应的一行。  
这类料天然就是"成片白木"与"成片油带"交替 —— 若按"白木是否成片"判，  
会一律落到 ×0.80，等于把纹路特征当成油量不足，系统性压低一整类标的。

→ 花纹料改按白木占比判，量化做法：对珠面做亮度阈值（深底照片先排除背景像素，  
阈值取背景亮度的 1.5 倍左右），数浅色区占珠面像素的比例：

| 浅色区占珠面    | 系数    |
| --------- | ----- |
| > 35%，且成片 | ×0.80 |
| 15 – 35%  | ×1.00 |
| < 15%     | ×1.25 |

⚠️ 深底照片里有光源衰减造成的阴影，会把"暗"算多 —— 阈值法只用于估比例，  
结论仍要人眼复核；两种读法（×1.00 / ×0.80）差 25%，卡片里应写明取的是哪一个及依据。

⚠️ 别用"以点带面"这类说法定档。 同样一句"油集中在纹带、其余偏干"，  
可以读成"局部偏干（×1.00）"，也可以读成"大片干涩（×0.80）"，两档差 25%。  
必须落到"成片可见"还是"局部可见"这个可数的观察上。  

⚠️ 油润感（判真假）与油脂分布（判价格）是两个维度：  
油润感看"整体润不润"，油脂分布看"油够不够、匀不匀"。

### 3.2 珠径系数

| 珠径       | 单颗克重   |
| -------- | ------ |
| 7–8 mm   | 0.27 g |
| 8–9 mm   | 0.34 g |
| 9–10 mm  | 0.45 g |
| 10–11 mm | 0.61 g |
| 11–12 mm | 0.84 g |

单颗克重列是几何参照（供密度反算交叉核对），不是价格系数。

⚠️ 珠径不设价格系数，一律 ×1.00。方向不分档位一致：通货料小珠克价略高（108 佛珠工费摊派、
小珠易取小块高油料做沉水），高油好料大珠更贵（≥18mm 大圆珠需整块无裂好料，有市场口径称
反比小珠高 50% 以上）。方向分歧 → 量级亦无据，不设系数；拿到同产区同规格实测价之前，不作珠径调整。

⚠️ 随形件不套珠径系数（该项置 ×1.00）。随形件没有"珠径"这个概念，  
形态价差一律由形状系数承担（含损耗与工艺），不要拿等效边长去凑珠径档位，  
也不要把形状系数读成"尺寸系数"。

### 3.3 形状系数

方向：圆珠 > 桶珠 > 鼓珠（苹果珠）> 随形 > 片片珠。  
随形 ≈ 同料同克重圆珠的 1/3，片珠用剩料最便宜。  
机制自洽（这条最硬）：圆珠综合损耗 70–80%（成品率 ≈ 原材 1/4），随形顺料修磨损耗仅 15–20%  
→ 材料成本比 ≈ 3 : 1，与市场"1/3"对得上 —— 加工损耗是形态价差的唯一主因。

| 形状               | 系数                 | 依据                                                                                                                                          |
| ---------------- | ------------------ | ------------------------------------------------------------------------------------------------------------------------------------------- |
| 圆珠               | × 1.00             | 基准形态。同料同克重下最贵（最费料）                                                                                                                          |
| 桶珠               | × 1.00（方向 <1）      | 费料仅次于圆珠；无量级来源 → 保守按 1.00                                                                                                                    |
| 鼓珠／苹果珠           | × 1.00（方向 <1）      | 比桶珠再省料；无量级来源 → 同上                                                                                                                           |
| 随形件              | × 0.33             | 多源一致：同料同克重圆珠的 1/3（区间 0.25–0.40）                                                                                                             |
| 片片珠／片珠           | × 0.20（保守推断）       | 市场口径"用剩料、最便宜"；低于随形，无量化来源                                                                                                                    |

⚠️ 本表只允许"向下修正"用于估价。  
方向有据、量级无据 → 一律取 ×1.00，方向只写进说明（桶珠／鼓珠同办）：取 1.00 属保守偏高 —— 宁可低估也不虚高，卡片注明口径。  
唯一给了量级的是随形 ×0.33（与损耗机制双支撑），其余形状都只有方向。

⚠️ 别把「料好」当成「形制贵」。 随形之所以"看着用料好"，是因为同样的钱买到了油更好的料  
（预算花在材质而不是损耗上）—— 那是料质优势，不是随形这个形态本身值钱。  
形态与料质必须分开计价：料质走油脂系数（§3.1），形态走本表。把两者混在一处就是重复计价。

#### ⚠️ 与 base 的配合：形状系数只能与 base 二者取一

| base 来源                      | 形状系数怎么取                         |
| ---------------------------- | ------------------------------- |
| 推演桥成品基准（默认路径：1.1 表原料价 × 3–5） | 按本表照常调 —— 桥给出的是圆珠／手串口径          |
| 同形态专项价（现查到随形件／桶珠专项价并直接采用时）   | 取 ×1.00 —— 基准里已含形态，卡片写明「基准已含形态」 |

两道都上 ＝ 双重计价（随形先按随形基准取低档、再乘 ×0.33，会被连砍两刀）。  
规则同 `SKILL.md`：「标的形态是什么，基准就必须取同形态」。

### 3.4 幅度对比（决定优先级）

油脂分布幅度 56%（×0.8–1.25）是系数里幅度最大的一项；珠径不设系数（方向分歧 → 一律 ×1.00，见 §三 3.2）。  
→ 先判油脂分布，再定形状。

## 四、完整估价公式

```
估价上限 = 克单价档位 × 克重 × 油脂系数 × 形状系数
估价区间 = [上限 × 0.7 , 上限]
```

### 上限档位怎么定

> 首要原则：标签没兑现 ≠ 要降档。

产区名（文莱／达拉干／马尼涝／正区）、品级名（软丝／黑棋／树心油）、结香方式（生结／熟结）  
图片分不出、检测也证明不了 —— 只说明"不能凭这一项加价"，不构成降档理由；  
拿标签降档会系统性压低整类标的，明确禁止。

定价分三步走：

① 先用可核实项定"材质能支撑的档"。  
可核实的只有三类 —— 密度等级（沉水／沉水浮／不沉水）、克重／珠径、  
外观（纹路是否自然、油脂是否成片）。由它们决定落档。

⚠️ 两个可核实项互相冲突时（如克重反算密度高 ↔ 外观成片白木），不许择一静默采用，也不许互相抵消。  
按三步处理：

1. 先用物理极限收窄解空间 —— 密度 ≤1.2（天然上限）→ 反推珠径下限，把不可能的解直接砍掉
2. 两个信号都保留、都写进卡片，并明确点出"二者不能同时成立"
3. 估价口径：基准档只按克重（密度反算）给，外观的分歧只在油脂系数上体现一次，不重复扣档；  
   卡片里注明"若以另一信号为准，上限会变成多少"，并把能裁定冲突的实测项列为第一号待确认

⚠️ 珠径未实测时怎么定档：① 用密度上限反推珠径下限 → ② 在可行区间内取最可能单值 →  
③ 卡片必须写明"珠径按 Xmm 计（推定，非吊牌标注）"，并标出敏感性（每 ±1mm 掉几档）。  
推定值不许当实测值静默使用 —— 它是这类标的的第一号变量，必须显式标出。  

② 标签只做一件事：兑现了才给溢价，没兑现就只取消溢价 —— 两者都不降档。

| 标签与可核实项的关系                                               | 定价作用                                         |
| -------------------------------------------------------- | -------------------------------------------- |
| 自洽（密度达标签等级 + 外观对得上 + 克单价合理）                              | 取该档（含产区溢价）；产区部分仍标注"未核实"                      |
| 不兑现（密度不达标签等级／品级名与外观不符／克单价倒挂）                             | 只取消该项溢价，按实测材质档定价，不额外降档                       |
| 无法核实（产区／品级名不可核，其余项普通）                                    | 中性，按材质支撑档                                    |
| 名号与流通现实不自洽（极度稀缺名品：母树／富森红土／芽庄白棋…）                         | 取消该名号溢价，按实测材质档；卡片写「标签存疑」，仍不降档                |

> ⚠️ 「不兑现」不是降档理由（双重惩罚：溢价本就没给，再砍一刀）。降档的理由只能是  
> 料本身有问题，不能是标签写错。

③ 料本身有问题时的处置（与"标签写没写对"无关）：

| 情形                                        | 处置                       |
| ----------------------------------------- | ------------------------ |
| 材质本身存疑：外观疑似非沉香／明显杂木特征／处理料（压缩沉、注油、染色、描画油线） | 不出估价上限，结论走 §5.2「建议回避」    |
| 标签堆叠 > 3 项，且无可核实项支撑其档位                    | 按材质档，不额外上浮               |
| 克单价倒挂（一线产区标签却报低价）                         | 按材质档（密度决定），不按产区档         |

> ⚠️ 「品级名与外观不符」（如标"软丝"却低油白木占主导）不在此表内 —— 那只是标签没兑现，  
> 取消溢价即可，不降档。判"材质存疑"看的是料本身（是不是沉香、料质有没有被改造）；  
> 标签不对扣的是"溢价理由"，不是"料的价值"。
>
> ⚠️ 高抛、抹油／煮油／泡油、微压同属造假（`treatment-marks.md` §1），只美化品相、不改造料质  
> —— 与本表第一行同归 §5.2「建议回避」，都不出估价上限。

### base（档位克单价）取值链 —— 只有一条路径

1. 同产区 + 同密度档 → §一 1.1 表原料价区间 × 3–5（推演桥，
   `region-benchmarks.md` §二 2.3）→ 得成品基准区间
2. 表内该格无报价（「-」）→ 联网现查该产区原料／车珠料口径价 → 直接补进 1.1 表
   （`region-benchmarks.md` §三 3.1 第 2 条）
3. 联网也查不到 → 不出估价上限。 只写"落在哪一档"的量级描述，并明写「基准未核实」。

⚠️ 形态是独立于产区、料档、规格的一根轴。  
推演桥给出的是圆珠／手串口径的成品基准；标的不是圆珠时，由形状系数（§三 3.3）
承担形态差异 —— 不得拿别的形态的行情价直接顶替基准：

| 标的形态       | 基准取法                                               | 不能拿这些顶替   |
| -------------- | ------------------------------------------------------ | ---------------- |
| 圆珠手串       | 推演桥直接用（桥口径即圆珠）                           | 原材、碎料价     |
| 桶珠／鼓珠手串 | 推演桥 + 桶／鼓珠形状系数（方向 <1，量级无据 → ×1.00） | 圆珠成品行情价   |
| 随形件         | 推演桥 + 随形形状系数 ×0.33                            | 圆珠手串行情价   |
| 原材／车珠料   | 1.1 表原料价直接用（不过桥、不乘成品系数）             | 成品手串价       |

> ⚠️ 同产区查不到原料价（表内「-」、联网也查不到）时：不出上限。可比产区顶替  
> （同香系、同级别、同密度档）只作「粗略参照」并明写；跨香系或跨级别的价不得顶替。

| 允许 | 禁止 |
| --- | --- |
| 判"这串落在哪一档"、给量级描述 | 拿跨产区参照价宣判"超上限 N 倍／买贵 N 倍" |
| 明写「基准未核实，区间可能整体偏低」 | 不加说明直接出估价区间 |
| 把"该去查哪个产区／档位"写成待办 | 用相邻产区或相邻档位的数字静默顶替 |

> ⚠️ 顶替的两个固有失真：① 跨产区平均 —— 套溢价产区必然失真（同档 ≠ 同价）；
> ② 档位跨度大（同一格内部可差数倍）—— 取哪一端要在卡片写明依据。

base 从区间里取哪一端：

- 默认取中位（推演区间 = 原料区间下沿 ×3 到上沿 ×5）
- 证据链完整（吊牌实测 + 密度达标签 + 纹路自然无处理痕迹）→ 取上端
- 料质的细腻差别不在这里扣，交给油脂系数 —— 避免重复扣档

> ⚠️ 不要把"建议上限"先定成整数、再倒算克单价。 反过来的话，  
> 克单价会变成一个凑出来的数，失去可复算性 —— 也再没人能复核这个数是怎么来的。  
> 正确方向是：base × 克重 × 系数 = 上限。

⚠️ 料有问题的判定要对每一串都套一遍，不能只对"看着最可疑的那串"套，否则同批口径不一致。  

### 弱基准下的方向性结论

不出上限 ≠ 不出价格结论。 同产区同档基准缺失时，仍按参照带出具方向性结论，
让结论对买家有用；上限价继续不给。

参照带按证据强度分级，结论语气随级递弱：

| 级 | 参照带来源 | 能出具的结论 |
| --- | --- | --- |
| A | 同产区同密度档原料价（表内或现查补表） | 全结论：值得争取 / 买得值 / 价格合理 / 超上限 |
| B | 同产区邻密度档（跨档，明写） | 方向性：不构成买贵 / 偏向值得争取 / 高于参照带上沿 |
| C | 同香系同档跨产区（明写不作同基准） | 方向性（弱）：同上，必须带「跨产区」限定 |
| D | 合并行、泛产区统价 | 只作量级下探参考，不单独支撑结论 |

方向性结论的判定（有成交价或商家定价才出）：

1. 挂牌克单价低于修正参照带下沿 → 「不构成买贵；偏向值得争取」
2. 落入带内下半 → 「落在参照带内偏下」
3. 高于带上沿 → 「高于参照带上沿，溢价未获证据支撑」

两分支锚定 —— 产区／品级名不参与定价，但要做最保守分支：

- 假设名号完全不实，回落到通用口径（同香系同档跨产区或入门档）再算一次
- 最保守分支下仍不高于参照带下沿 → 方向性结论成立
- 最保守分支下买贵 → 方向性结论不出，只写「两分支结论分裂」

红线不变：不出上限的字面保留；参照带明写证据等级与「不作同基准」；
区间不写单值；不许先定上限再倒算。

### 两条硬规则

1. 倍数只能跟同一产区比（柬埔寨料对柬埔寨价），不跨产区比价（见 `region-benchmarks.md` §四 4.1）
2. 倍数必须带基准 —— "超上限 N 倍"相对本估价上限；"超同产区零售 N 倍"相对本产区市场挂牌。  
   两个口径不可混用，写卡片时必须标明用的是哪个。

## 五、结论分档

结论分两类，落位不同，别混着写。

### 5.1 价格类 → 写进卡片的「估值区间」块

⚠️ 这一组必须先有成交价（或商家定价）。没有成交价时整组不写，  
只给估值区间、不下"值不值"的判断——没有基准的倍数结论是空话。

| 结论       | 触发条件                                 |
| -------- | ------------------------------------ |
| 值得争取     | 成交价低于估价上限，且证据相对完整（吊牌 + 密度自洽 + 纹路自然）  |
| 买得值      | 成交价明显低于上限，且材质无疑点 → 性价比高              |
| 价格合理·不必退 | 成交价落在估价区间内                           |
| 超上限      | 成交价高于上限 → 建议对抬 / 退货 / 不碰，按超出倍数分级     |
| 偏向值得争取（弱基准） | 基准为 B／C 级参照带，挂牌低于修正参照带下沿，且最保守分支（名号不实）仍不买贵 |
| 不构成买贵（弱基准） | 基准为 B／C 级参照带，挂牌不高于参照带上沿 → 只否定「买贵」，不同时认定「便宜」 |

超出倍数分级用语（倍数一律相对本串估价上限，不要说成"市场均价 N 倍"）：

- 超上限 1 倍以内 → "溢价偏高，可不追"
- 超上限 1–5 倍 → "建议退货"
- 超上限 > 5 倍 → "建议不碰"

### 5.2 材质类 → 写进卡片的 verdict

材质类结论不看价格：东西不对，多便宜也是全损。只写结论，不出估价上限。

| 结论           | 触发条件                                                                                   |
| ------------ | -------------------------------------------------------------------------------------- |
| 建议回避         | 密度不达标，或料本身有问题 —— 疑似非沉香／明显杂木特征／改造料质的处理料（注油、压缩沉、注胶、香精、染色、描画油线）／可靠识别的外观处理（微压、高抛、抹油／煮油／泡油） |
| 建议回避 · 线索不充足 | 只有"线索"级迹象（高压、微注油、煮油／抹油／泡油、染色）—— 有疑点，但证据不足以定论                                           |

⚠️ 只有"线索"级迹象时，同样写「建议回避」，也同属"不出估价上限"的一类；  
但结论行必须带限定语 —— 「建议回避 · 线索不充足，建议补拍后重判」，  
并在同一段列明要补拍／实测的具体项。  
"有疑点但证据不足"不等于"没问题"：不出价 + 不建议碰，是这一档的一致口径。
