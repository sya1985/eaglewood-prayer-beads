# 图像观察要点

> 图片只能做初筛，不能做材质定性。CM160 卡片里所有结论都写成
> "存疑 / 材质待验 / 建议做 CMA"，申诉理由用"描述与实物不符"而不是"假货"。

---

## 一、四个观察维度（按这个顺序看）

### ① 纹路

看的是珠面油脂线（结香树脂沿韧皮部沉积形成的油线）的形态与走向，以及白木部分的木纹、导管痕迹。

判真假的全部判据统一在 `treatment-marks.md`。本文件只保留一句正面特征：

- 天然料：油脂线连贯随性、深浅有渐变、每颗走向各异

产区纹相旁证（只查相容性，不查身份 —— 看图分不出正区／偏区，见 §六）：

| 标签声称的产区 | 可图辨的纹相旁证 |
|---|---|
| 达拉干／马尼涝 | 黑油粗线常成片，黑白对比强（俗称虎斑／片油） |
| 菩萨省 | 虎斑纹：油线深浅交错成斑块 |
| 文莱（正区） | 油脂细腻，油线密集均匀 |
| 惠安系生结（芽庄／顺化） | 油线沿导管细密渗透，少见大片黑油 |
| 加里曼丹／巴布亚通货 | 油线稀疏，常见成片白木 |

相容 ≠ 证实：纹相相符只能写「纹相与声明相容」，不得写成「即该产区」；
不相容 → 写进待确认。香味不可图辨，油色非产区判据，均不作旁证。

### ② 颜色

- 同串色差越小越好
- 跨黑褐到橙红的大跨度 → 指向混料或染色深浅不一
- 颜色鲜艳均匀且与木纹走向无关 → 染色线索
- 出现纯白木珠 → 白木，非结香部分

### ③ 油润感（判真假）

- 真沉香高油是微黏的润，反光温润、油脂透亮
- 干哑无光 → 油不足
- 硬亮抛光感（玻璃／塑料感）→ 高抛痕迹
- 油光浮在表面而非从内部透出 → 抹油线索

### ④ 油脂分布（判价格，主导系数）

- 油线是否贯通连续
- 每颗含油量是否接近
- 有无局部干白芯
- 结论：全串均匀油润（×1.25）／不均（×1.00）／大片干涩（×0.8）

⚠️ ③ 与 ④ 是不同的东西：③ 看"整体润不润"，④ 看"油够不够、匀不匀"。

## 二、颗数：必须从整串图逐颗数

颗数直接决定密度。同克重下，17 颗和 20 颗差一个等级。

- 优先用能看清每颗的整串图逐颗清点
- 深底微距图最好数
- 数不出来时明确写"颗数待确认"，并按区间给密度，不要猜一个具体数字

---

## 三、珠径：三级证据强度

| 证据 | 强度 | 用法 |
|---|---|---|
| 吊牌标注珠径（文字朝向不定，按实际朝向读取） | 最可靠 | 直接代入公式 |
| 克重 ÷ 颗数 = 单颗克重 → 反推球径（需先有密度假设） | 间接 | 配合密度区间给珠径区间 |
| 整串图几何反推（圆环外径像素 ÷ 颗数像素） | 参考 | 只能给 7–8mm 这种粗档 |

卡片里珠径必须写成区间或标"待确认"，不得写成单值。

## 四、吊牌处理技巧

- 吊牌朝向不定——正、倒置、歪斜都可能。读之前先确认文字方向，倒置或歪斜就先转正再读；不要假定它一定是倒的，也不要假定它一定是正的
- 先自动定位白底亮块再裁剪，手试坐标会偏
- 读出的信息：克重、珠径、产地标签、退换警示
- ⚠️ 退换警示类文本（"温馨提示""标签撕毁不退换"）是行业通用条款，不是标的信息，
  不要当成标的特征或减分项写进卡片

## 五、让用户补拍的六种角度（判不出来时主动要）

| 角度 | 能看出什么 |
|---|---|
| ① 吊牌正面特写（水平拍摄） | 克重／珠径／产地标签真伪 |
| ② 孔道口放大 | 注油／注胶痕迹 |
| ③ 每颗并排对比 | 染色色差、抹油不匀 |
| ④ 逆光／侧光 | 高抛硬反光 vs 温润透亮 |
| ⑤ 自然光不修图 | 抹油／染色最容易露馅 |
| ⑥ 微距图（比 ② 更近，要能看清纤维／孔道结构） | 三大结构（韧皮部／导管／木射线）是否完整、有无变形糊化 → 处理痕迹的硬判据（见 `treatment-marks.md` 微距判据表） |

## 六、能力边界（写卡片时必须遵守）

能做：排序疑点（谁最可疑、谁相对可信）、密度反算、纹路归类、价格区间。

不能做：
- 定性造假 —— 只有 CMA 检测（含乙醇提取物 ≥ 10%）+ 常温冷水沉水实测 能定性
  （⚠️ 别与「可靠识别」混：见 `treatment-marks.md`——杂木外观即可判，高压、微注油需微距图；
  它们可作为卡片里的硬伤写出，但那只是观察结论的强度分级，不等于 CMA 的法定定性）
- 看图分辨正区／偏区（正区贵 30%–50%，外观几乎一样）
- 看图判断香味、手感、注胶

克重本身可能报错：密度是从克重反算的，卖家报错克重则密度结论同样失效。
→ 卡片需注明"吊牌克重与上手称重都要核"。
